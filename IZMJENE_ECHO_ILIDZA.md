# ECHO Ilidža – dorada početne stranice

Vizuelni pravac: prvobitni korisnikov koncept (tamnozelena, limeta, signalni talas, snažan slogan, statistika na slici, tri informativne kartice).

## Promjene

- Naziv ECHO Ilidža, bez riječi „Civic“ u vidljivom interfejsu, naslovu kartice i osnovnim opisima.
- Logo i favicon sada koriste motiv zvučnog talasa iz prvobitnog koncepta.
- Slogan: „Problem ne nestaje. Ali može dobiti odjek.“
- Ujednačen blaži sjaj i manje dekorativnih oznaka na naslovnoj fotografiji.
- Statistika prikazana niže uz fotografiju; brojevi se i dalje računaju iz stvarnih lokalnih testnih prijava.
- Kartica posljednjih prijava prikazuje pohranjenu fotografiju, ako postoji; inače ikonu kategorije.
- Poboljšani stilovi naslovne sekcije i mobilnih prikaza.
- Podnožje: „Pametniji grad. Aktivniji građani.“

## Namjerno neizmijenjeno

Prijavljivanje, mapa, administracija, rute i pohrana podataka. Nije dodat grb Općine niti tvrdnja o službenoj saradnji. Mini-mapa je i dalje shematski prikaz položaja prijava, a ne izmišljena geografska granica Općine. Originalna AI ilustracija ostaje označena kao takva.

## Pokretanje

U korijenu projekta: `npm install`, zatim `npm run dev`. Za provjeru: `npm test` i `npm run build`.

U ovom radnom okruženju nije bilo moguće završiti npm test/build: ZIP je sadržavao nepotpunu Windows instalaciju node_modules, dok je Linux native modul Rolldown nedostajao. Zbog toga je potrebno provesti provjeru na računaru s ispravnom npm instalacijom prije objave.
